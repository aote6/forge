# Forge 产品裁定：最小启动路径

状态：有效
前置：FORGE_IDENTITY.md

只定启动与运行条件，不展开协议与目录。

## 一、运行条件

Forge 必须接入一个可用的 AI 才能进入可工作状态。

- 具体模型与接入方式可替换
- 没有可用 AI：可以安装、可以启动进程，但不能正常作为 Agent 工作

## 二、Veritas

Veritas 是可选连接的下层机器，**不是**启动条件。

- 不连接：仍可启动并使用不依赖 veritasd 的能力（读、搜、规划、一般 shell 等）
- 连接并在线：工程写入主路径可走 Veritas 事务（见 `FORGE_VERITAS_STANCE.md`）

最小路径 **不要求** 先装 Veritas。

## 三、最小启动路径

```
安装 Forge
  → 启动
  → 接入可用 AI
  → 进入可工作状态（至少：对话 + 只读类/本地工具）
  → 使用
```

不绑定：Key 存哪、具体模型、平台、安装包格式、是否安装 Veritas。
