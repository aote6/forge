# Forge 产品裁定：最小启动路径

状态：冻结
前置文档：FORGE_IDENTITY.md

本文件是 Forge 身份定义之后的第一份产品裁定。
只裁定已经确定的事实，不进入实现讨论。

## 一、Forge 的运行条件

Forge 必须接入一个可用的 AI 才能进入运行状态。

- 具体 AI 可替换
- 具体接入方式可替换
- 但“存在一个可用 AI”不是可选条件，而是运行条件

没有可用 AI 时，Forge 可以被安装、被启动，
但不进入可工作状态。

## 二、Veritas 的地位

Veritas 是可选连接的下层机器。

- 不连接 Veritas，Forge 仍可运行，处于只读工作形态
- 连接 Veritas 后，Forge 进入可变更工作形态
- Veritas 不是 Forge 的启动条件；它是进入可变更工作形态的条件

## 三、最小启动路径

用户从拿到 Forge 到开始使用，最小路径为：

安装 Forge

→ 启动 Forge

→ 接入可用 AI

→ Forge 进入可工作状态

→ 用户开始使用

该路径不绑定以下内容：

- API Key 的存储方式
- 具体模型
- 具体 AI 接入方式
- 平台形态
- 安装包格式
- 是否连接 Veritas
