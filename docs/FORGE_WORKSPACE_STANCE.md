# Forge 与用户工作空间

状态：有效
前置：FORGE_IDENTITY.md、FORGE_PRODUCT_STANCE.md

只划边界：谁是本体、谁是外部对象。不谈具体目录布局。

## 一、本体与工作空间

- **Forge 软件本体**：可安装、可启动的那套系统（实现可换）。
- **用户工作空间**：用户交给 Forge 操作的目录/项目，属于用户，不是 Forge 本体。
- **运行状态**：会话、缓存、日志等，既不是本体，也不是用户项目本身。
- **Forge 源码**：仍是本体；若被当作工作对象操作，是在演化自身，不等于降格成普通用户数据。

四者不要混成一层。

## 二、对工作空间实际怎么动（跟当前实现）

- **读 / 分析 / 搜索**：不依赖 Veritas。
- **经 Forge 主路径的创建 / 修改 / 删除**：当前实现走 Veritas 事务；无 veritasd 则该主路径不可用。
- **shell 等旁路**：实现上可能改盘，但不进入 Veritas 证据链（见 VERITAS 立场）。

本文件不规定「禁止用户改自己的文件」。

## 三、边界摘要

| 层级 | 含义 |
|------|------|
| 软件本体 | Forge 系统 |
| 用户工作空间 | 外部对象 |
| 运行状态 | 可清理、可重建 |
| 源码 | 本体，可被当作工作对象 |
