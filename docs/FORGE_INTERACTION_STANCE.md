# 用户交互模型

状态：有效
前置：FORGE_IDENTITY.md

只定交互原则，不定 UI 布局与命令表。

## 一、目标驱动

用户表达希望达成的目标；不是靠一堆配置项驱动核心工作。

自然语言是当前主要输入方式；原则本身不绑死某一种输入。

## 二、目标 → 执行 → 结果

用户不必手动管理内部每一步编排。  
Forge 按目标调用工具并反馈结果（成功、失败原因、或主路径不可用说明）。

无 Veritas 时若目标依赖事务写入，应如实反馈主路径不可用，而不是假装改成功。

## 三、多前端同一本质

CLI / TUI / GUI / Web 等都可以换皮。

共同模型：

```
用户表达目标 → Forge 执行 → 返回结果
```

## 四、终端 UI

Claude Code 式终端可以是当前合适前端之一，不是身份，也不是唯一形式。
